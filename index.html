About Me

I am a PhD student at Zhejiang University, advised by Prof. Shuibin He. My research focuses on efficient LLM training and inference. I work on KV cache compression for long-context inference, scheduling across decentralized and heterogeneous GPU clusters, and architecture-aware optimization for AI accelerators.

First-Author Publications

  • InQuant: An In-Place Mixed-Precision Quantization Method for KV Cache Compression with Neighbor Invasion

    NeurIPS · InQuant code

    Reuses neighboring channel slots to keep important KV cache channels at higher precision while quantizing in place. The open-source implementation has been used in Sugon and Huawei Kunpeng inference projects.

  • SpiderFlow: Topology-Aware Scheduling for ML Training Across Decentralized GPU Clusters

    ACL (Main)

    Uses cluster topology to schedule training jobs and automates parallelism configuration for jobs that run across clusters.

  • Frenzy: A Memory-Aware Serverless LLM Training System for Heterogeneous GPU Clusters

    Euro-Par · Preprint · Frenzy code

    Predicts GPU memory requirements and uses those estimates to allocate GPUs for serverless training jobs. Results from Frenzy were applied to the Nanhu scheduling system at Zhejiang Lab.

Ongoing Research

  • FrostKV: Hot-Cold Aware KV Compression for Offload-Efficient Long-Context LLM Inference

    Uses attention activity to identify hot and cold KV blocks and entropy-codes cold blocks to reduce memory use and offload traffic. Related compression algorithms have been used by H3C’s storage team.
